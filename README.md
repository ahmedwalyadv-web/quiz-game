# 🧠 لعبة الأسئلة (Quiz Game) - تطبيق ويب كامل

تطبيق زي "لعبة السبنر" بالظبط: سيرفر Node.js حقيقي + قاعدة بيانات SQLite، بدون أي تسجيل دخول للاعبين. كل كامبين (لعبة) ليه رابط لاعبين منفصل، وكل جهاز يفتح الرابط يلعب بشكل مستقل تمامًا عن باقي الأجهزة. الأسئلة والهوية بالكامل عربي/إنجليزي، والألوان والنمط (Pattern) قابلين للتخصيص الكامل من لوحة التحكم.

- **صفحة اللعبة** (`/play/<رابط-الكامبين>`) - بدون تسجيل دخول، تفتح فل سكرين (Fullscreen)، بها زرار تبديل لغة لو فعّلت الاختيارين.
- **لوحة تحكم إدارية** (`/admin`) - حساب أدمن (يتعمل تلقائيًا أول مرة)، وبتتحكم في: الهوية والألوان والخط ونمط الخلفية (مع قوالب جاهزة زي "اليوم الوطني")، الأسئلة (نص/صورة/فيديو عربي وإنجليزي، اختيارات متعددة مع تحديد الإجابة الصحيحة)، عدد الأسئلة والتوقيت (لكل سؤال أو وقت إجمالي)، شروط الفوز/الخسارة (تلقائي أو إجباري)، ونتائج كل اللاعبين مع تصدير Excel.

الإجابة الصحيحة بتتحدد وتتخزن في السيرفر دايمًا (مش في المتصفح) عشان محدش يقدر يغش بفتح أدوات المطور.

---

## 1) التشغيل محليًا

يحتاج [Node.js](https://nodejs.org) إصدار 18 أو أحدث.

```bash
npm install
npm start
```

هيفتح على `http://localhost:3000` - لوحة التحكم على `/admin`. أول تشغيل هيطبع في الطرفية اسم مستخدم وكلمة مرور الأدمن الافتراضية (`admin` / `admin123`) - غيّرها فورًا من زرار "كلمة المرور" في الداشبورد.

تقدر تحدد بيانات الأدمن من البداية بعمل `.env` (انسخ `.env.example`) وتعدّل `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`JWT_SECRET`.

## 2) الرفع على Render (بنفس طريقة لعبة السبنر)

1. ارفع المشروع على GitHub (مجلد `node_modules` مستبعد في `.gitignore`).
2. من [dashboard.render.com](https://dashboard.render.com) اعمل **New → Web Service** واربطه بالريبو.
3. Runtime: Node — Build command: `npm install` — Start command: `node server/index.js`.
4. **مهم جدًا**: ضيف **Persistent Disk** (1GB كفاية) وحطه Mount Path على `/app/persist` (أو أي مسار تختاره).
5. ضيف Environment Variable: `DATA_DIR` = نفس الـ Mount Path اللي حطيته (مثلاً `/app/persist`)، وكمان `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `JWT_SECRET` بقيم قوية من عندك.
6. بعد النشر هيديك رابط عام (Domain) - ده رابط لوحة التحكم `/admin`، وأي كامبين تعمله هيكون ليه رابط لاعبين تحته `/play/<رابط الكامبين>`.

## 3) نسخة احتياطية

كل بياناتك (الكامبينات والنتائج) في ملف `data/quiz.db`، والصور/الفيديوهات المرفوعة في `public/uploads/` - أو جوه القرص الدائم (`DATA_DIR`) لو مستضاف. اعمل نسخة احتياطية دورية منهم.
